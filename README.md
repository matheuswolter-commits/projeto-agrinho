# 🌿 AgroTech Sustentável: O Futuro da Agricultura Conectada


Uma landing page moderna projetada para demonstrar como a tecnologia de ponta (como IA, drones e sensores IoT) pode aumentar a produção de alimentos no campo reduzindo drasticamente o impacto ambiental.

---

## 🎯 Objetivo do Projeto

O objetivo principal deste projeto é demonstrar o quanto a tecnologia pode ajudar na agricultura. Queremos mostrar que a transformação digital e a preservação ambiental caminham juntas, trazendo soluções que ajudam o produtor rural a economizar recursos e proteger o solo.

A página explora o impacto de tecnologias como:
* **Internet das Coisas (IoT):** Sensores que medem a umidade do solo e evitam o desperdício de água.
* **Inteligência Artificial:** Análise de dados para prever o clima e planejar a colheita.
* **Drones:** Monitoramento aéreo para identificar pragas rapidamente, reduzindo o uso de químicos.

---

## 🚀 Funcionalidades da Landing Page

* **Design Responsivo:** Funciona perfeitamente em celulares, tablets e computadores.
* **Seção de Impacto:** Demonstração visual de como a tecnologia reduz o desperdício no campo.
* **Navegação Simples:** Estrutura direta focada em conscientizar o visitante.
* **Formulário de Contato:** Para produtores interessados em saber mais sobre tecnologia agrícola.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias básicas da web:

* **HTML5:** Para estruturar todo o conteúdo da página.
* **CSS3:** Para deixar o visual moderno, bonito e organizado.
* **JavaScript:** Para colocar interatividade e animações na página.



## 📦 Como Executar o Projeto

Como o projeto usa tecnologias simples da web, você só precisa de um navegador:

1. Baixe os arquivos do projeto para o seu computador.
2. Dê um duplo clique no arquivo `index.html`.
3. O site abrirá automaticamente no seu navegador de internet.
